## Release sorting failure

Input column: `[30, 10, nil, 20]`.

Descending indices should be `[0, 3, 1, 2]`, producing `[30, 20, 10, nil]`.

The Release build instead returns `[1, 3, 0, 2]`, producing `[10, 20, 30, nil]`. The Debug build returns the expected order. Sorting a column without missing values passed the isolated control check in both configurations.

The relevant code is `Sources/SwiftDataFrame/Columns/TypedColumn.swift`, particularly the optional-value helper at line 335. Its source comparison appears consistent with the documented missing-values-last contract. The isolated reproduction rules out interference from concurrent upstream tests and confirms the original input is preserved. The remaining issue involves optimized compilation on this toolchain; this evaluation has not established whether the underlying defect belongs to the compiler or the library.

No workaround was patched into upstream source, and no failing assertion was weakened. Avoid relying on the affected Release sorting path. All Debug tests passing is evidence for local evaluation, not a guarantee of correctness outside the cases exercised.
