# Milestone 4: core migration and research boundary

The agreed scope is a validated core migration with explicit research retention for noncomparable model-training, GPU and other legacy experiments. Kiraa refers here to the unofficial development build with known bugs. It is an optional experimental reference, never a correctness oracle or production baseline.

## Coverage

The executable inventory reconciles 135 registrations: 111 timed cases, 22 Python accuracy results and two untimed Swift diagnostics. Sixty registrations map to standardized replacement contracts. Seventy-five remain research entries with specific unresolved requirements. These counts describe registrations, not unique algorithms. Replacement contracts do not certify historical results or preserve every historical problem size.

The migration profiles contain 36 cases. They cover streaming and mixed-type CSV, joins, Parquet reading and writing, grouped reductions, row iteration, correlations, hypothesis tests, error metrics, ROC-AUC, one-hot encoding, TF-IDF, SQLite ingestion, the legacy empty-frame RAG summary, and constant-image pooling/Dice. Original table and NIST profiles remain separate. The Python adapter uses pandas, NumPy, SciPy, PyArrow and SQLite according to the operation. Model and GPU workloads remain available through explicit `--research` entry points. Legacy fuzzy-name comparison is retired.

## Defects exposed by independent validation

The initial mixed-fixture run failed two Parquet cases. SwiftSci's writer omitted required metadata, compressed page headers and wrote unpacked Boolean bytes. Its reader also expected unpacked Boolean bytes. Own-library round trips concealed these format problems. The isolated production repair writes standard metadata and pages, handles packed Booleans, and preserves the existing fallback reader for old SwiftSci files. Regression fixtures include externally generated nullable values and a retained legacy file. Every measured Parquet write is read by pinned PyArrow outside timing and retained with a checksum.

Independent review found that the first ANOVA replacement used two groups although the legacy cases used three. The corrected workload prepares x, y and z=(x+y)/2 before timing and validates all result fields against a separate high-precision reference, including two between-group degrees of freedom.

A final binary audit found that Xcode still emitted Swift coverage instrumentation despite the Clang coverage setting. The v4 outputs passed their correctness checks, but those timings are diagnostic only. They are retained separately. The builder now uses package-level Release `build-for-testing` with `-enableCodeCoverage NO`, and both build and run reject actual Mach-O binaries containing LLVM profile or coverage sections. Contract v5 prevents comparison with earlier measurement contracts. The regression gate rejected the original instrumented binary before the new measurements were run. Earlier build records without this absence check should not be used as production timing baselines. The first attempted fix used a testing-only Xcode flag and failed with exit 64; plain-build coverage settings also failed to remove instrumentation. The package test-build action above is the correction verified by the final binary gate. No new timing run used that failed build.

## Validation and limits

The final contribution commit is `a9a5539e893f8b0d269c27603b753ac7e965ffb0`. All 72 migrated smoke cases, 54 NIST engine cases and 28 original smoke cases passed alongside the larger run. All four evidence audits passed, and comparing v4 with v5 was rejected. Final counts and unresolved timing samples are in `final-results.json` in the evidence archive. Debug and Release each passed 905 native tests with zero failures or skips. All 479 production source, native test and package files match that tested snapshot. Later changes affect benchmark workers, the controller and its tests; the final compiled worker is checked end to end. The Python contract suite passed 46 tests.

Passing this suite does not certify the entire library or establish numerical stability for arbitrary inputs. The timed mixed fixtures have finite numeric values, restricted category strings and Boolean values. Nullable Parquet coverage comes from regression tests. NIST coverage remains the nine univariate datasets for mean, variance and standard deviation. Research model/GPU cases, broader data distributions, fitted-state reuse, calibrated tiny operations and formal performance thresholds remain outside this increment. Samples below the timing-resolution threshold remain unresolved and receive no speedup ratio.

The conformance workflow now installs pinned dependencies before testing, reconciles the inventory and runs the migrated smoke profile alongside the original smoke and NIST cases. The v5 large run passed all 216 processes and 1,080 measured output checks. Thirty measured Parquet files passed independent validation. Fifteen tiny-operation timing samples remain unresolved; they were retained and do not support speedup claims. The hosted GitHub workflow has not run for these unpublished commits.

## Contribution boundary and evidence

Implementation, public contracts, fixture attribution and usage instructions belong on `codex/standardized-benchmarks`. This report, the private plan, decision trail and local run records belong only on `codex/engineering-notes`. The contribution-history guard checks for leaked internal paths. No contribution PR is created by this work.

The evidence archive is `Documentation/EngineeringNotes/archive/2026-09-26/migration4/`. It retains run records, certificates, native test summaries, build identity, source-match evidence, review notes and a checksum manifest. Accepted run directories have a `-v5` suffix. Earlier captured runs explain defects and instrumentation; their timings are diagnostic only. Raw measured Parquet files and full Xcode logs remain in the ignored local run/cache directories; their hashes and validation records are retained. The archived JSON records alone are not a portable copy of every measured file.
