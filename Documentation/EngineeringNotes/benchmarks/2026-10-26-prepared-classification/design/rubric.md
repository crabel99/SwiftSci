# Private synthesis rubric

Score each criterion0..3 with evidence.

1. Complete caller path through prepared ClassifierEstimator existential and ClassificationPipeline; legacy conformers continue to compile.
2. Removes nested row expansion and repeated epoch scratch allocation without new global mutable cache or broad feature-view framework.
3. Preserves Double/Float arithmetic, update/accumulation order, epochs0, threshold and device resolution; concrete conformance verification.
4. Schema and finite/shape validation, source/target/provenance ownership, consistent failed-refit and actor behavior.
5. Small public surface and short implementation call chain, reuse existing prepared and GPU completion boundaries, no unrelated classifier/agent changes.
6. Clear Xcode27 validation plus Swift6.3.3 compatibility strategy, production versus engineering evidence separation.
