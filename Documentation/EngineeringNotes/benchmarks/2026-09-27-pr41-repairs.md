## Decisions and evidence

| Commit | Reproduced fault | Choice and validation |
| --- | --- | --- |
| `17378c40bb` | Supplied linear weights cannot predict; native reload fails through the same initializer. | Initialize the resolved device and both parameter representations. Automatic supplied-weight models retain CPU Double arithmetic; explicit GPU/ANE requests follow existing GPU routing. Fixed-affine prediction, both fresh-process reload variants, four device choices, and retained Double precision pass. |
| `a5650c090b` | Supplied logistic weights cannot predict. | Initialize the same state for the classifier in its own commit. Complete probabilities and labels pass the independent fixture; device tests retain the strict threshold behavior at a zero logit. |
| `46c34538d2` | Identical nonzero vectors of magnitude 1e-7 have cosine zero. | Scale each operand by its largest magnitude before computing norms and the dot product. Removing the cutoff alone would leave underflow and overflow. The original case and unit checks from 1e-300 through 1e300 pass, including opposite, orthogonal, and zero vectors. This adds one query buffer and scalar normalization work per entry. It makes no search-throughput claim. |
| `7abcc5bee8` | Truncated PCA reports 1.0 instead of 0.8. | Retain total fitted variance separately from selected component variance. Full decompositions use the complete spectrum; randomized SVD uses the centered matrix norm. The latter adds a pass over its existing centered matrix. Exact-model, solver-selection, and refit checks pass. |
| `894b48566b` | Public decoder loading leaves attention weights unchanged. | Map checkpoint keys to MLX's registered projection names instead of Swift property names. CPU/GPU fixtures pass exact parameter readback and complete independent logits; unit tests check every attention projection in multiple layers. |
| `fde7536865` | Two-batch GPU cached RoPE logits differ from independent answers. | The pinned MLX single-token dispatch counts heads but omits batches. Fold batch and head axes together under a single batch for that call, then restore the shape. This keeps the pinned dependency and position/cache semantics. The independent failure and deterministic full/cached comparisons for one, two, and three batches pass. Reshaping may materialize storage depending on layout. Revisit when the dependency's dispatch is repaired. |
| `9e62f2f3aa` | Six ANOVA cases fail exact-binary64 references. | Keep means relative to observed values and compensate sums, with a separate within-group origin for each group, avoiding cancellation when small differences sit on large offsets. The implementation avoids a flattened data copy. All six retained cases and analytical translation checks pass. It cannot recover decimal information lost before the function receives a Double. |
| `dbf83fca2b` | Wampler4/5 coefficients miss the fixed tolerance. | Retain multiplication and addition roundoff in residuals and residual gradients. Solve correction equations through the existing QR triangular factor without forming a normal-equation matrix. Accept at most three finite corrections that reduce the scaled gradient. Changing LAPACK drivers or column scaling alone did not resolve the observed failures. Both reference bases pass, along with an independent polynomial/noise regression. Refinement adds bounded passes over the data and small triangular solves; speed remains unqualified. |
| `36053baca6` | Core ML rejects the composite scaler/regressor with `Feature descriptions exceeded 1`. | Compose valid scalar scaler stages while preserving named Double inputs and outputs. Stage overlapping names before publishing outputs. Apple requires exactly one input and one output feature per Scaler; its GLM validator accepts multiple scalar inputs. Both fresh-process workflows and executable exporter tests pass, including swapped names. Multiple features now incur pipeline stages and a larger model artifact. |

The three-correction limit bounds the extra OLS work. It is not a convergence guarantee or a new rank-revealing solver. The existing analytical-solver fallback remains. Revisit this choice when broader conditioning or rank-deficiency contracts supply evidence beyond the current fixtures.

The native regressor reload is one manifestation of the linear initializer fault, so it shares that commit. Decoder loading and batched rotary execution are distinct faults and remain separate. The scalar export repair preserves the public interface instead of requiring callers to provide a newly named vector input.

Apple format references: [Scaler validation](https://github.com/apple/coremltools/blob/main/mlmodel/src/Validation/ScalarValidator.cpp) and [linear model validation](https://github.com/apple/coremltools/blob/main/mlmodel/src/Validation/LinearModelValidator.cpp). The evidence records the inspected validator URLs and hashes. The RoPE diagnosis uses the locally pinned dependency source, not a claim about every MLX version.

The first complete acceptance run at `6d55299403` recorded 1,142 passes from 1,152 engine-case executions, ten retained failures, and zero infrastructure errors. Review then exposed a gap in the initial ANOVA repair: using one common origin for within-group variance could lose small differences in a group far from that origin. An analytical example failed when groups `[1e16, 1e16 + 2, 1e16 + 4]` and `[0, 1, 2]` were listed in that order. Each group's own origin preserves its internal variation; both orders now meet the analytical bound. The red test log and intermediate Git bundle preserve this correction history. The bundle requires the original PR base commit.

The final all-tier acceptance run covers all 24 profiles and all 1,152 required engine-case executions. It records 1,142 passes, ten retained failures, complete evidence coverage, and zero infrastructure errors. Twenty-two profiles pass their audits. ## Reproduction and limits

Use the public commands in `Benchmarks/README.md`: build the worker, run the native and controller suites, then execute `Benchmarks/Tools/acceptance.py --tier all` with a fresh output directory. The evidence includes the isolated build helper used for faster incremental checks. It copies changes from the pinned PR base into a stable compilation snapshot and retains the standard source, binary, and toolchain checks. The final source hashes were also checked directly against every corresponding snapshot file.

Diagnostic timing samples remain diagnostic. This work does not establish a formal performance baseline, production memory guarantees, predictive quality, or certification beyond the recorded workload contracts. Keep the original-decimal limitations and reference-engine failures visible when reporting acceptance. Neither a shared failure nor a successful unrelated profile changes the status of a failing case.

The evidence archive retains baseline and repaired responses, complete acceptance records, unit/controller logs, build identity, verification helpers, and inspected external validator identities. Its manifest binds each retained file by path, size, and SHA-256. Requests preserve original absolute paths for provenance; the committed fixture generators and standard runner provide the portable rerun interface.
